# Скрипты для развёртывания VPS

## 1. server_full_setup.sh
Выполняется на сервере от root. Настраивает:
- пользователя
- SSH (порт, ключи, запрет root)
- iptables
- sysctl для VPN (3x-ui)
- автообновления
- fail2ban
- красивый prompt и fastfetch

## 2. part2_local_key_setup.sh
Выполняется на локальном компьютере. Создаёт SSH-ключ и копирует его на сервер.

## Порядок запуска
1. Запустить `server_full_setup.sh` на сервере
2. Запустить `part2_local_key_setup.sh` на локальном компьютере
3. Подключиться по SSH на новом порту
